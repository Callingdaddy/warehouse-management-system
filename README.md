# Warehouse Management System

A responsive Warehouse Management System built using **HTML, CSS and vanilla JavaScript**.

## Features
- Dashboard with inventory KPIs
- Product inventory management (add, edit, delete)
- Search and category filtering
- Stock In / Stock Out tracking
- Low-stock alerts
- Order creation and fulfillment
- Order status management
- Inventory value calculation
- Browser localStorage persistence
- Responsive admin dashboard

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- Browser LocalStorage API

## How to Run
1. Download/clone the repository.
2. Open `index.html` in any modern browser.
3. No backend or installation is required.

## Internship Project
This project demonstrates frontend development, DOM manipulation, form validation, state management, CRUD operations, filtering, and local data persistence.
